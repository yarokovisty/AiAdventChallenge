# Week 1 / Day 1 — Первый запрос к LLM

## Задание

Написать минимальный код, который отправляет запрос к языковой модели через API и показывает ответ.

---

## Что было сделано

Написал Android-приложение — простой чат с LLM. Интерфейс: поле ввода внизу, список сообщений выше. Отправляешь текст — получаешь ответ от модели.

Приложение сохраняет историю переписки и передаёт её в каждом запросе, так что модель помнит контекст разговора.

**Модель:** GLM-5.3 через API платформы Z.ai

**Стек:** Kotlin, Jetpack Compose, MVVM, OkHttp

---

## Что пришлось решить по ходу

- Изначально использовалась модель `glm-4-flash` — она была удалена с платформы. Пришлось переключиться на `glm-5.3` и сменить endpoint.
- Стандартный HTTP-клиент имеет 10-секундный таймаут. GLM-5.3 на развёрнутых запросах отвечает за 60–90 секунд — таймаут пришлось увеличить до 120 секунд.
- Клавиатура перекрывала поле ввода. Причина — конфликт между режимом `adjustResize` в манифесте и `enableEdgeToEdge()`. Решилось через `imePadding()` в Compose и `adjustNothing` в манифесте.

---

## Итог

Приложение работает: принимает сообщения, отправляет запрос к GLM-5.3, показывает ответ, сохраняет историю. Все базовые сценарии проверены — пустые сообщения блокируются, длинные ответы скроллируются.
