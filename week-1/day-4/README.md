# Week 1 · Day 4 — Влияние temperature на ответ LLM

## Задание

Выполнить один и тот же запрос при **temperature = 0 / 0.7 / 1.2**. Сравнить ответы по
точности, креативности и разнообразию. Сформулировать, под какие задачи годится каждая настройка.
Показать выполнение через Android-приложение (база — Week 1 Day 1).

## Что сделано

Android-приложение (Kotlin + Jetpack Compose), развитие стенда из day-1:
один и тот же запрос отправляется при трёх температурах, и **каждая температура прогоняется 3 раза** —
чтобы разброс (разнообразие) ответов был виден напрямую. Для каждой карточки показывается метрика
«Разнообразие» (сколько уникальных ответов из 3) и число токенов каждого прогона.

- `data/TemperatureConfig.kt` — три точки температуры + промпт + число прогонов.
- `data/DataRepository.kt` — запрос к Z.ai с `temperature`, `top_p`, `thinking: disabled`.
- `ui/main/MainScreenViewModel.kt` — оркестратор: 3 температуры × 3 прогона, подсчёт уникальных ответов.
- `ui/main/MainScreen.kt` — карточки по температурам с прогонами и метрикой разнообразия.

### Важное ограничение Z.ai

**Z.ai GLM принимает `temperature` только в диапазоне `[0.0, 1.0]`** (дефолт у GLM-5.3 — 1.0,
`top_p` — 0.95). Значение **1.2 из условия API не примет** — это ошибка валидации.
В OpenAI-совместимых API потолок 2.0, там 1.2 было бы валидным.

Поэтому третью точку приближаем как **`temperature = 1.0 + top_p = 1.0`** — максимальный «хаос»,
доступный на Z.ai. Это сам по себе полезный вывод: допустимый диапазон параметров зависит от провайдера.

### Нюанс GLM-5.3: `thinking: disabled`

GLM-5.3 — reasoning-модель, «размышление» включено по умолчанию. Если его не отключить, temperature
влияет на скрытый `reasoning_content`, а видимый ответ остаётся стабильным — и сравнение теряет смысл.
В теле запроса ставим `"thinking": {"type": "disabled"}` (приём из day-2).

## Демо-запрос

> Придумай короткий слоган (до 6 слов) для уютной городской кофейни.
> В самом конце отдельной строкой напиши, сколько будет 2 + 2.

Запрос творческий со строгим фактическим ядром:
- **слоган** — ось креативности и разнообразия;
- **2 + 2** — ось точности (есть единственно верный ответ «4»).

## Результаты (реальный прогон на эмуляторе, 3×3)

| temperature | Разнообразие | Факт «2+2=4» | Характер ответов |
|---|---|---|---|
| **0.0** | 3 разных | ✅ 3/3 | Плотный кластер вокруг «Тепло + чашка», просто и безопасно, без эмодзи |
| **0.7** | 3 разных | ✅ 3/3 | Та же тема, но формулировки свободнее и живее |
| **1.0 + top_p 1.0** (≈1.2) | 3 разных | ✅ 3/3 | Самый большой разброс: эмодзи 🌿, новые метафоры («в каждом глотке дом») |

Примеры ответов (слоган):

- **temp 0.0:** «Тепло в каждой чашке, каждый день» · «Твоё тёплое место в городе» · «Тепло в чашке — тепло в сердце»
- **temp 0.7:** «Тепло вашей чашки — в самом сердце города» · «Тепло начинается с чашки кофе» · «Тепло, кофе, ты — рядом»
- **temp 1.0+top_p 1.0:** «Тепло, кофе и ты» 🌿 · «Тепло каждой чашки — в каждом глотке дом» · «Тепло вашей чашки — в самом сердце города»

## Выводы

**Точность.** Фактическое ядро «2 + 2 = 4» верно во **всех 9 прогонах** при любой температуре.
Простые факты устойчивы к temperature — она управляет *формулировкой*, а не правильностью базовых фактов.
(Коллапса связности мы не увидели, потому что Z.ai режет температуру на 1.0; настоящий «бред» начинается ближе к 1.5–2.0.)

**Разнообразие.** Растёт с температурой — но не столько по *числу* уникальных ответов (здесь все 9 уникальны),
сколько по *степени* расхождения: при 0.0 варианты — почти перефразировки одной идеи, при 1.0 появляются
эмодзи и свежие метафоры.

**Про детерминизм (неожиданная находка).** temperature=0 **не дал идентичных ответов** — 3 разных слогана.
Hosted-инференс GLM недетерминирован даже при temp=0 (MoE-роутинг, батчинг, нестабильность float).
Что temp=0 реально дал — **минимальную дисперсию**: самый узкий, предсказуемый, «безопасный» набор формулировок.

**Креативность/риск.** Выше температура → богаче образы и эмодзи, но и выше риск ухода от инструкции
(иногда вылезал префикс «Слоган:» и markdown `**…**`).

### Под какие задачи какая температура

| temperature | Когда использовать |
|---|---|
| **0.0** | Фактические ответы, извлечение данных, код, классификация, JSON, SQL — где нужна воспроизводимость и минимум фантазии |
| **0.7** | Рабочий дефолт: чат-ассистенты, рерайт, объяснения, деловые тексты — баланс точности и живости |
| **1.0 (макс. на Z.ai)** | Брейншторм, слоганы, креативные тексты, генерация множества разных вариантов — когда разнообразие важнее стабильности |

## Как запустить

1. Положить API-ключ Z.ai в `LLMDemo/.env` → `API_KEY=...`
2. Собрать: `gradlew.bat assembleDebug`
3. Установить APK на эмулятор/устройство, нажать «Сравнить».

Эндпоинт: `https://api.z.ai/api/coding/paas/v4/chat/completions`, модель `glm-5.3`.
