# AI Advent Challenge — Дневник прохождения

Этот репозиторий — мой личный дневник прохождения курса **AI Advent Challenge**.
Здесь я фиксирую выполненные задания, веду заметки по каждому дню и отслеживаю прогресс за все 7 недель курса.

---

## Что такое AI Advent Challenge

**AI Advent Challenge** — 7-недельный курс по практическому применению AI.
Каждую неделю выходит 5 заданий (по рабочим дням), итого **35 заданий** за весь курс.
Цель курса — научиться эффективно работать с AI-инструментами: от базовых промптов до построения полноценных AI-приложений.

---

## Структура репозитория

```
AiAdventChallenge/
├── README.md               # Этот файл — главная страница дневника
├── week-1/                 # Папка первой недели
│   ├── day-1/              # Задание первого дня
│   │   ├── README.md       # Условие задания и заметки
│   │   └── solution.*      # Файл с решением
│   ├── day-2/
│   ├── day-3/
│   ├── day-4/
│   └── day-5/
├── week-2/
│   └── ...
...
└── week-7/
    └── ...
```

Каждая папка `day-N/` содержит:
- `README.md` — условие задания, подход к решению, выводы и заметки
- файлы с решением (код, промпты, артефакты — зависит от задания)
